witness fixes that. before anything leaves the room, it gets stamped.

$witness --help /// how it works
--make
make stuff with your AI. however you already do. claude, gpt, gemini, local model, mixed media, doesn't matter. make the work.
--stamp
stamp on the way out. before the session ends, run the work through witness. each artifact gets a davw block. the session itself gets a merkle root. one signed bundle, plain text.
--keep
keep the receipt. email it to yourself. commit it to git. file it with TD commons. dropbox, USB stick, tattoo on your forearm. anywhere a text file goes, the proof goes.
--verify
anyone, anytime. sha256sum + a clock. that's the dependency tree. no SDK, no service, no expiring tokens. the proof outlives the platform that made it.
$cat mythos.md /// the small things
01
the 1-pixel air gap. every davw block carries a 1×1 png, base64-embedded. the verifier requires it. strip the pixel, the proof fails. your name lives in the white square no one notices.
02
dual clock. ISO timestamp and unix seconds. edit one without the other and the block falls apart. catches half-clever tampering automatically.
03
self-reference. the block declares its own SHA-256, then declares the payload as davw:<that-same-hash>. the file points at itself. if anything in the body changed, the pointer breaks.
04
session nonce binding. you give the AI a 16-char random string at the start. every artifact carries it. an adversary who replays an artifact across a different session can't fake the nonce.
05
merkle root. the session bundle commits to all artifacts at once, in a single hash. tamper with one, the root breaks visibly.
06
plain text. no binary. no proprietary parser. goes anywhere. gets read in 50 years. survives the platform that made it.
