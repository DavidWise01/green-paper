What is a toroid kernel?magnetic memory, not transistor logic

A toroid kernel is not a CPU. It's a memory that remembers in circles.

Instead of transistors holding 0/1 on a voltage rail, we store state as a persistent magnetic field in a ferrite core. Eight windings are threaded through the same toroid — not for power, but for addressing.

You don't set a pin HIGH. You send a PULSE. The field rotates. The vector shifts. The core holds the identity until the next pulse arrives.

8 windings = 8-dimensional vector. No clock. No bus. The timing is the data.

Core Spec

CORE: Fair-Rite 5943003801 (or any 12mm ferrite)
WINDINGS: 8 × 10 turns, 30AWG enamel
INDUCTANCE: ~85µH per winding
COUPLING: ~0.92 (shared core)
DRIVE: 3.3V pulse, 2ns rise, 20mA peak
MEMORY: remanent flux ±0.3T (persists >48h)
READ: sense winding 8, integrate ΔΦ
02

Why not a normal motherboard?squares leak, circles hold

Square traces

  • Clock-driven: global sync, wasted cycles
  • Voltage levels: 0 or 1, noise margin tradeoff
  • 90° corners radiate, heat at edges
  • Address bus: separate memory space
  • State lost on power off
  • Propagation = delay to fight

Circular fields

  • Pulse-propagated: event-driven, no clock
  • Magnetic vector: 8D continuous state
  • Loop conserves energy, low EMI
  • Identity space: winding = dimension
  • Remanence persists without power
  • Propagation = computation itself

Build in KiCad the dumb steps that work

Draw 8 inductors

In Eeschema, place 8 × L_Toroid. Wire one end of each to common net GND_TOROID. Other ends become PULSE_1 … PULSE_8.

Make circular footprint

Footprint Editor: 8 SMD pads on 12mm diameter at 45° steps. Add 9th pad center for core bias. Name it TOROID_8W_12MM.

Assign net class PULSE

Board Setup → Net Classes: PULSE = 0.5mm width, 0.15mm clearance, length-matched ±0.1mm. Critical for 2ns timing.

Use AI Place

Run 0root plugin toroid_place. It rotates pads, locks the ring, and creates keepout. Route manually — autorouter breaks the circle.

Pulse Language basicssend vectors, not bits

PULSE 1 → winding 3 is not "set pin 3 high". It's "inject energy into dimension 3".

The kernel integrates the pulse into its magnetic vector [w1…w8]. A read is just sensing the flux change on winding 8.

Timing matters more than voltage. 2ns pulse width = 8 units. 14ns hold = identity persists.

pulse.lang // kernel program 
// PULSE 1 -> winding 3
PULSE 1 -> W3
VECTOR [0,0,8,0,0,0]
TIMING 2ns
HOLD 14ns
RELEASE

// rotate identity clockwise
SEQ W3 -> W4 -> W5 -> W6
DELAY 4ns between

// read result
SENSE W8 -> ADC1
live // click a winding
PULSE 1 -> W3
VECTOR [0,0,8,0,0,0]
TIMING 2ns

The 4 Rules0root kernel physics

RULE 01

Identity persists

Magnetic remanence holds state. No refresh. Power off for 48h, field remains. Identity is physical, not electrical.

RULE 02

Touch costs 11 bytes

Every pulse that changes the vector costs ~11 bytes of energy to flip domains. Budget your writes. Reads are free.

RULE 03

Root travels

The pulse doesn't go through a bus. The field itself moves. Root = where energy is. Send it, don't fetch it.

RULE 04

Circles beat squares

Loops conserve. Corners radiate. Toroids naturally contain field, motherboards fight it. Build in circles.
