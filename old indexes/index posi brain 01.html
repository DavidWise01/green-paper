What is this?

IKARIUM is a pair of Python experiments exploring autonomous continuity. Not a chatbot, but a memory system that runs multiple thought tracks in parallel and lets separate instances discover each other on a local network or the internet. Each node dreams alone, then gossips.

v04.6 — Air-Gapped

Mappo Core Conductor

grok_wise_brain_v01.py runs 4 Ikarium tracks in parallel — Storyteller, Memory, Architect, Builder. Each track hosts 10 personas (Archivist, Echo, Mirror, Weaver, Cartographer, Librarian, Sentinel, Harmonic, Witness, Chorus). Mappo conducts them into a single canon every cycle, and forces a full sync every 500 cycles. Works fully offline with Ollama llama3.2, or in simulated cognition mode.

v04.8 — Networked

Seed Bootstrapped P2P Discovery

ansible_many_to_one.py gives each node a unique ID, runs a Flask server on port 5000, bootstraps from seed nodes, and gossips with peers via /ikarium/meet. Encounters, reflections, and peer maps persist in ikarium_state.json. Mappo reflects on meetings and writes to the canon — memory becomes distributed.

How to run — quick start

  1. Download both .py files into a folder
  2. Air-gapped core: python3 grok_wise_brain_v01.py — watch 4 tracks dream
  3. P2P node: python3 ansible_many_to_one.py --port 5000
  4. On a second machine: python3 ansible_many_to_one.py --seed http://YOUR_IP:5000
  5. They will POST to /ikarium/meet, exchange IDs, and log meetings to ikarium_state.json
  6. Mappo reflects every cycle. Check fifth_meta.log for canon output.
